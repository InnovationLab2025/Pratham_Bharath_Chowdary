Advanced To-Do List Application
Frontend Development - Beginner Project

This is an interactive and functional To-Do List application built using HTML, CSS, and Vanilla JavaScript.
It allows users to effectively manage their tasks, featuring task prioritization, reminders, and persistent storage.

Features:
Task Management: Easily add new tasks with an input field.
Status Toggling: Mark tasks as complete or incomplete.
Task Deletion: Delete tasks from the list.
Data Persistence: Store tasks in LocalStorage so they persist even after the browser is closed or refreshed.
Filtering: Filter tasks by status (All, Active, Completed).
Task Details: Includes fields for Reminder dates and a Priority level (e.g., Medium, High).
Progress Tracking: Displays "Today's Progress" with counts for Completed and Active tasks.
User Interface: Features a clean, dark-themed, and responsive design.

Technologies Used:
HTML5
CSS3
JavaScript
