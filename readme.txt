Dynamic Weather Dashboard
Frontend Development - Beginner Project

This project is a dynamic and interactive web application that serves as a Weather Dashboard. 
It utilizes a third-party Weather API to fetch real-time and forecast data, displaying it in a modern, user-friendly interface.

Features:
Search Functionality: Allows users to search for weather by city name using an input field.
Current Weather: Displays current weather conditions, including:
     Temperature
     Weather description
     Humidity
     Wind Speed
     Local Time of the city.
5-Day Forecast: Shows a 5-day weather forecast with the day of the week, temperature, weather condition, and an icon.
Unit Toggle: A button to easily switch the temperature display between Celsius [C] and Fahrenheit [F].
Weather Icons: Uses weather icons and animations to visually represent the current and forecast conditions.
Error Handling: Built to handle API errors gracefully.

Technologies Used:
HTML5
CSS3
JavaScript
Weather API
